# Notices tierces

Ce fichier recense le code repris d'autres projets dans libcoadd, avec les notices de copyright et
de licence que ces projets exigent de conserver. libcoadd lui-même est distribué sous
`GPL-3.0-or-later` (voir [`LICENSE`](LICENSE)) ; chaque projet repris reste soumis à sa propre
licence, rappelée ci-dessous.

Aucun projet tiers n'est repris pour l'instant.

## Ce qu'il faut noter pour chaque projet repris

Ajouter une section par projet, sur le modèle suivant :

```markdown
### <nom du projet>

- **Source** : <URL du dépôt ou de la publication d'origine, avec la version ou le commit repris>
- **Licence** : <identifiant SPDX, par exemple `MIT`>
- **Copyright** : <titulaires du copyright, tels qu'ils figurent dans le projet d'origine>
- **Fichiers concernés** : <fichiers ou dossiers de libcoadd qui contiennent ce code>
- **Texte de la licence** : <texte intégral ci-dessous, ou renvoi vers le fichier qui le contient>
```
